Ingin menambahkan komputer baru ke GoMesh?

Daftarkan komputer remote (Linux, Windows, atau macOS) dengan satu baris perintah instalasi otomatis.

GoMesh • High Performance Remote Management • Built with Pure Go

Tambahkan Komputer Target (Agent)

Pilih sistem operasi komputer target untuk melihat perintah instalasi instan

default-token

Jalankan perintah ini di terminal server / komputer target Linux (Ubuntu, Debian, CentOS, RHEL):

curl -sSL http://localhost:8080/scripts/install-linux.sh | sudo bash -s -- -s ws://localhost:8080/ws/agent -t default-token

• Script otomatis mengunduh binary, mendaftarkan service systemd, dan menjalankan agen di background.

Jalankan di PowerShell Administrator pada komputer Windows target:

powershell -ExecutionPolicy Bypass -Command "Invoke-WebRequest -Uri http://localhost:8080/scripts/install-windows.ps1 -OutFile install.ps1; .\install.ps1 -ServerUrl ws://localhost:8080/ws/agent -Token default-token"

• Menggunakan Windows Service API resmi (sc.exe) tanpa UPX packer sehingga aman dari false-positive antivirus.

Jalankan di Terminal macOS target:

curl -sSL http://localhost:8080/scripts/install-macos.sh | sudo bash -s -- -s ws://localhost:8080/ws/agent -t default-token

• Mendaftarkan LaunchDaemon sistem di /Library/LaunchDaemons/com.gomesh.agent.plist.

Download Standalone Binaries Langsung:

Linux (gomesh-agent-linux) Windows (gomesh-agent.exe) macOS (gomesh-agent)
