Smart Roaming Dual-Network (LAN + Internet)

Agent otomatis cerdas: saat di kantor menggunakan LAN (kecepatan maksimal & hemat kuota), saat user pulang ke rumah otomatis pindah ke Internet / Cloudflare.

Auto-Switching
Auto-detected
Interface Router:

Digunakan saat user di kantor (bisa beda VLAN/ethernet selama di-routing oleh MikroTik).

Luar Jaringan

Digunakan saat user pulang ke rumah / remote luar kantor.

Peringatan: Alamat LAN masih localhost!

Komputer lain tidak bisa menghubungi localhost. Masukkan IP LAN server (klik saran: 192.168.1.5:8080) atau isi Fallback Internet di atas.

Download Installer Langsung via Web:

Windows

Windows 10, 11, Windows Server (64-bit). Bebas antivirus warning.

Download Auto-Run .exe (Siap Pakai) Installer Service .bat
Linux

Ubuntu, Debian, RHEL, CentOS. Terintegrasi dengan systemd service.

Download Auto-Run Binary Installer Service .sh
macOS

macOS Monterey, Ventura, Sonoma, Sequoia (Apple Silicon & Intel).

Download Auto-Run Binary Installer LaunchDaemon .sh

Atau Jalankan Perintah Terminal Langsung:

curl -sSL http://localhost:8080/scripts/install-linux.sh | sudo bash -s -- -s ws://localhost:8080/ws/agent -t default-token

• Mengunduh binary, mendaftarkan systemd service, dan otomatis berjalan sebagai daemon.

powershell -ExecutionPolicy Bypass -Command "Invoke-WebRequest -Uri http://localhost:8080/scripts/install-windows.ps1 -OutFile install.ps1; .\install.ps1 -ServerUrl ws://localhost:8080/ws/agent -Token default-token"

• Jalankan di Administrator PowerShell. Mendaftarkan Windows Service via sc.exe resmi (aman antivirus).

curl -sSL http://localhost:8080/scripts/install-macos.sh | sudo bash -s -- -s ws://localhost:8080/ws/agent -t default-token

• Mendaftarkan LaunchDaemon sistem di /Library/LaunchDaemons/com.gomesh.agent.plist.
